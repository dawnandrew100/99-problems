# 99-problems
This repository contains solutions to the classic **Ninety-Nine Prolog Problems**, originally published at [prof.ti.bfh.ch](https://prof.ti.bfh.ch/hew1/informatik3/prolog/p-99/).

If the original link becomes unavailable, the problem statements are also preserved in the [problems.md](https://github.com/dawnandrew100/99-problems/blob/main/problems.md) file within this repository.

Solutions are implemented in multiple programming languages, including **Python**, **C**, and **Assembly**, showcasing different paradigms and approaches to logic-based problem-solving.


## Introduction

The purpose of this problem collection is to give you the opportunity to practice your skills in logic programming.
Your goal should be to find the most elegant solution of the given problems.
Efficiency is important, but logical clarity is even more crucial.
Some of the (easy) problems can be trivially solved using built-in predicates.
However, in these cases, you learn more if you try to find your own solution.
